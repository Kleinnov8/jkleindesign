# Justin Klein Design | Creative Technologist

A professional portfolio and technical "training gym" built with **Vue 3** and **Vite**.

## 🚀 The Vision
This site serves as my professional digital headquarters, showcasing my multi-disciplinary expertise in:
*   **Web & App Development:** Modern, high-performance web applications.
*   **IT & Hardware Solutions:** Custom workstations and complex infrastructure.
*   **Creative Design:** Visual branding and multimedia production.

It also acts as a foundational project ("Training Gym") for my upcoming complex web application, **DreamDungeon.AI**.

## 🎨 Design Aesthetic: "Red & Glass"
The site implements a custom **Glassmorphism** theme, inspired by a beautiful Web 2.0 site I stumbled upon about 20 years ago, which made a huge impression on me as a designer.
The Aesthetic:
*   **Pearly White Glass:** High-transparency containers with 15px backdrop blur.
*   **Metallic Red Accents:** Deep, bold gradients (#8a0b0b) for key UI elements.
*   **Central CSS Strategy:** Adheres to a strict global stylesheet approach for consistent branding without the complexity of scoped component styles.

## 🛠️ Tech Stack
*   **Framework:** Vue 3 (Composition API)
*   **Build Tool:** Vite
*   **Routing:** Vue Router 4
*   **Styling:** Centralized, Custom CSS
*   **Deployment:** Netlify
